# 🧰 ربات جعبه‌ابزار بله (Bale Toolbox Bot)

رباتی برای پیام‌رسان **بله** که بعد از `/start` یک **منوی شیشه‌ای (دکمه‌های inline)** نشان می‌دهد و ۷ ابزار دارد:

| ابزار | توضیح |
|---|---|
| 📥 دانلود فایل | لینک مستقیم → دانلود با پیشرفت زنده؛ بالای ۲۰ مگ → پارت‌های ۲۰ مگی خودکار |
| 🔍 جستجوی گوگل | زنجیره‌ی Google → DuckDuckGo → Bing → Google News؛ شماره نتیجه → HTML همان صفحه |
| 🌐 دریافت HTML | سورس کامل صفحه + خلاصه متن + آمار تصاویر/CSS/JS/مدیا (با تگ base) |
| 📺 یوتیوب | جستجو؛ دانلود ویدیو تا 720p یا فقط صدا (mp3/m4a)؛ بالای ۲۰ مگ پارت می‌شود |
| 📌 پینترست | لینک پین → تصویر/ویدیوی اصلی با بالاترین کیفیت؛ جستجو هم دارد |
| ✈️ تلگرام | ورود به اکانت با پایروگرام (شماره → کد → 2FA)؛ دریافت زنده‌ی پیام کانال‌ها، دانلود مدیا از لینک، جستجو |
| 🐙 گیت‌هاب | ساخت ریپازیتوری، آپلود/کامیت فایل، ساخت ورک‌فلو اکشنز، لیست ریپوها |

> ⚠️ محدودیت‌های سرویس‌ها: دانلود یوتیوب و سرچ پینترست از IPهای دیتاسنتر (مثل Actions) گاهی محدود می‌شوند — روی IP شخصی/خانه کار می‌کنند یا با کوکی (`YT_COOKIES`). سرچ گوگل هم اگر اسکرپ بلاک شد خودکار به DuckDuckGo/Bing/Google-News سوئیچ می‌کند.

## 🚀 اجرا

```bash
pip install -r requirements.txt
export BOT_TOKEN='توکن ربات بله'
python3 main.py        # یا ./run.sh برای اجرای خودترمیم‌شونده
```

## ⚙️ متغیرهای محیطی

| متغیر | لازم؟ | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات بله (از @BotFather بله) |
| `OWNER_ID` | — | آیدی عددی کاربر مجاز؛ اگر ست شود بقیه رد می‌شوند |
| `GITHUB_TOKEN` / `GH_PAT` | — | PAT گیت‌هاب برای ابزار گیت‌هاب (یا از دکمه‌ی «تنظیم توکن» داخل چت) |
| `TG_API_ID` / `TG_API_HASH` | — | برای اتصال اکانت تلگرام (از my.telegram.org) |
| `YT_COOKIES` | — | محتوای cookies.txt نت‌اسکیپ برای دانلود یوتیوب |
| `CHUNK_MB` / `MAX_MB` / `WORKERS` | — | ۲۰ مگ / ۲۰۴۸ مگ / ۲ دانلود همزمان |
| `API_BASE` / `WORK_DIR` / `STATE_FILE` | — | `https://tapi.bale.ai` / `./work` / `./state.json` |

## ☁️ اجرای مادام‌العمر روی GitHub Actions

ورک‌فلو `.github/workflows/bot.yml`:
- هر اجرا تا **۳۴۰ دقیقه** ربات را روشن نگه می‌دارد؛ `cron` هر ۲۰ دقیقه اگر ربات خاموش باشد دوباره اجرایش می‌آورد (با `concurrency` بدون دوبل شدن).
- `keepalive.yml` هر هفته یک کامیت خالی می‌زند تا گیت‌هاب cron را بعد از ۶۰ روز خاموش نکند.
- **Secrets لازم**: `BALE_BOT_TOKEN`، `OWNER_ID`، `GH_PAT` (اختیاری: `TG_API_ID`، `TG_API_HASH`، `YT_COOKIES`)
- نکته‌ی مهم: مخزن باید **Public** باشد تا Actions ساعت‌های نامحدود رایگان بدهد (در مخزن خصوصی سقف ماهانه ۲۰۰۰ دقیقه است). کد هیچ توکنی داخلش ندارد؛ همه در Secrets اند.
- `state.json` (سشن تلگرام، توکن‌ها، کانال‌های اشتراک) بین اجراها با `actions/cache` حفظ می‌شود.

## 🔐 امنیت

- هیچ توکنی در کد هاردکد نیست؛ همه از متغیر محیطی/Secret خوانده می‌شوند.
- توکن گیت‌هاب و سشن تلگرام در `state.json` روی سرور می‌مانند (در `.gitignore` است).
- با `OWNER_ID` فقط شما به ربات دسترسی دارید.
- سشن تلگرام (پایروگرام) با خروج (دکمه‌ی «🔌 خروج») یا لغو سشن در تلگرام (Settings → Devices → Terminate) قابل ابطال است.

## 🖥 اجرای دائمی روی سرور شخصی (جایگزین Actions)

```bash
./run.sh   # حلقه‌ی خودترمیم: اگر main.py بمیرد ۵ ثانیه بعد دوباره بالا می‌آید
```

نمونه سرویس systemd هم در پایین همین فایل (نسخه‌ی قبل) آمده؛ فقط `Environment=BOT_TOKEN=...` را ست کنید.

## 🧱 ساختار کد

```
main.py            روتر پیام‌ها + منو + دانلودر (منطق تست‌شده)
botcore.py         لایه‌ی Bot API بله + وضعیت کاربران + ابزار مشترک
tools/gsearch.py   جستجوی چندموتوره
tools/htmlfetch.py دریافت و پارس HTML
tools/ytube.py     یوتیوب (yt-dlp + ffmpeg)
tools/pinterest.py پینترست
tools/gh.py        گیت‌هاب (REST API)
tools/tgram.py     اکانت تلگرام (پایروگرام، ترد جدا + event loop خودش)
```
